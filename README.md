# Glokom-Risk ML

Glokom-Risk ML is a machine learning based clinical decision support system designed to predict glaucoma risk using structured clinical data such as intraocular pressure, age, corneal thickness and other clinical features.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib / Seaborn
- Joblib / Pickle

## Machine Learning Models
- Random Forest Classifier
- Support Vector Machine
- Logistic Regression

## Dataset
The project uses a glaucoma detection dataset from Kaggle:
https://www.kaggle.com/datasets/teamincribo/glaucoma-detection-dataset

## Purpose
This project aims to support clinical decision-making by providing a fast, lightweight and explainable glaucoma risk prediction system.

## Disclaimer
This project is developed for educational purposes. It is not intended to replace professional medical diagnosis.
